In implementing a two-agent workflow, I can clearly see the distinction between AI "generation" from "verification". The Planner Agent's prompt, being generative as it is, can be as imaginative as possible (despite having to abide by user-centered constraints like budget or pacing). The Planner doesn't have to be responsible or worry about real-time data. This contrasts with the Reviewer Agent, where it acts as the verification and pragmatic layer that can check opening hours or over-scheduled days using an external, internet-searching tool. By compartmentalizing the workflow into specialized agents, I do believe that this makes the system more consistent than an all-encompassing single prompt (as this takes into account the limited context windows and attention of the system).

I also came accross a challenge when making the prompt: deciding what the Reviewer should always search for. I got through this by structuring a rule that the Reviewer has to follow, where, if there exists any time-immediate or high-risk item (e.g., inter-city trains), the Reviewer should call the `internet_search` tool to verify. This ensures that the tool is not only used, but used purposefully. Another big challenge is to ensure that the Planner's structure isn't overly modified after Reviewer's edits. I tried to make this clear by asking the Reviewer to generate its "Delta List" before generating a revised “Final Itinerary.” This enables the user to see the changes implemented and how they're applied. 

A design choice I made was adding various constraint-like notes in the prompts, thus making the style of the outputted itinerary more parsable to users (e.g., Don't get rid of good content from the planner...). In these notes, I also tried to add customized sections like, "If the user is solo-travelling, try to incorporate flexible evening...," to be as user-centered as I can, taking into account the different types of travelers. This overall holds the Reviewer and Planner accountable to what they'll output, especially making them do some sorts of internal chain-of-reasoning to output the most coherent itinerary as they can.

**External tools / GenAI used:** I used ChatGPT briefly to help organize the scaffold and structural integrity of my system prompts, ensuring the prompts encompassed all important requirements of the assignment (the scaffolds are mostly contain only titles and headers). I iterated on these scaffolds 2–3 times to improve on their clarity. However, I wrote all individual bullet-points and contents to own the work. Before submission, I also used the tool to clean up my grammar and syntax in case the prompt is unclear to the system.
